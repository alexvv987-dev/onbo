# Онбо

**Онбо (Onbo)** — ИИ-помощник для адаптации стажёров в новой команде.
Название образовано от слова onboarding.

Проект создаётся для кейса «AI-buddy: ИИ-наставник для стажёров»
хакатона Hack&Change 2026.

## Статус

Репозиторий подготовлен к разработке. Реализация приложения, зависимости,
инструкции запуска и тесты будут добавлены по мере разработки.

## Назначение

- Помогать стажёру находить ответы о процессах и инструментах команды.
- Показывать этапы адаптации, текущий статус и следующие шаги.
- Помогать выполнять организационные действия через корпоративные сервисы
  или их тестовые имитации.

## Требования к прототипу

- Реализовать 3–5 сценариев адаптации либо один глубоко проработанный.
- Хотя бы в одном сценарии выполнить действие через сервис или его имитацию,
  отобразить и сохранить возвращённый результат.
- Учитывать права пользователя при чтении данных и выполнении действий.
- Использовать синтетические или обезличенные данные. Тестовые инструкции
  должны быть явно обозначены и не выдаваться за регламенты Авито.
- Описать поведение ИИ-помощника и его инструментов в SDD-спецификациях.
- Обеспечить покрытие строк прикладного кода автоматическими тестами
  более 80% и приложить воспроизводимый отчёт.

Конкретные сценарии и архитектура пока не выбраны.
