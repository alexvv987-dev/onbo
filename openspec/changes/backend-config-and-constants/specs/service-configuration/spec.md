# Spec Delta

## Purpose

Обеспечивать воспроизводимую настройку Go-сервисов Onbo из YAML и окружения с предсказуемым приоритетом, ранним обнаружением ошибок и сохранением секретов вне конфигурационных файлов репозитория.

## ADDED Requirements

### Requirement: Приоритет источников конфигурации

Сервисы SHALL формировать настройки в порядке defaults, YAML, переменные окружения; последнее явно заданное значение имеет приоритет. Путь YAML SHALL задаваться через CONFIG_FILE либо стандартным путём соответствующего сервиса.

#### Scenario: Окружение переопределяет файл
- **WHEN** адрес HTTP задан в YAML и через HTTP_ADDR
- **THEN** используется значение HTTP_ADDR.

#### Scenario: Явное false
- **WHEN** YAML включает демо-режим, а DEMO_MODE имеет значение false
- **THEN** демо-режим отключён; false не принимается за отсутствие настройки.

### Requirement: Строгая загрузка файла

Сервис SHALL отклонять недоступный явно выбранный файл, неизвестные или повторные YAML-ключи, некорректные типы и несколько YAML-документов. При отсутствии стандартного файла и незаданном CONFIG_FILE сервис SHALL поддерживать запуск из defaults и окружения.

#### Scenario: Ошибка явного пути
- **WHEN** CONFIG_FILE указывает на отсутствующий файл
- **THEN** запуск завершается ошибкой конфигурации до подключения к зависимостям.

#### Scenario: Опечатка в параметре
- **WHEN** существующий YAML содержит неизвестный ключ
- **THEN** запуск отклоняется, а ключ не игнорируется молча.

#### Scenario: Существующий испорченный стандартный файл
- **WHEN** стандартный YAML существует, но некорректен
- **THEN** запуск завершается ошибкой, а не переключается на defaults.

### Requirement: Ранняя валидация

Сервис SHALL проверять итоговые настройки до сетевой инициализации: обязательные значения, известный режим LLM, корректные адреса и положительные длительности/лимиты. Duration SHALL задаваться строками с единицами времени; некорректное значение SHALL завершать запуск.

#### Scenario: Неверная длительность
- **WHEN** timeout имеет значение без единицы времени или отрицательное значение
- **THEN** запуск отклоняется с именем параметра без раскрытия его чувствительного содержимого.

#### Scenario: Условная необходимость модели
- **WHEN** выбран demo
- **THEN** ключ и модель GigaChat не требуются; при выборе gigachat они обязательны.

### Requirement: Секреты только из окружения

Секреты и полный DSN с учётными данными SHALL поступать из окружения. YAML SHALL содержать только разрешённые несекретные поля; секретные поля файла SHALL отклоняться. Ошибки и логи конфигурации SHALL не содержать ключи, пароли, токены или полный DSN.

#### Scenario: Ошибка подключения в конфигурации
- **WHEN** DATABASE_URL содержит некорректное значение с паролем
- **THEN** ошибка сообщает имя параметра без возврата полного значения и пароля.

#### Scenario: Секрет в YAML
- **WHEN** YAML задаёт пароль Redis или ключ GigaChat
- **THEN** конфигурация отклоняется; значение не выводится.

### Requirement: Совместимость запуска и поведения

Система SHALL сохранять существующие имена переменных окружения, значения по умолчанию для каждого Go-процесса, JSON-контракты и правила MVP при эквивалентных настройках. Проверка настоящей модели SHALL не требовать параметры БД и Redis и SHALL не допускать demo.

#### Scenario: Старый запуск из окружения
- **WHEN** стандартного файла нет, а необходимые прежние переменные заданы корректно
- **THEN** сервис запускается с эквивалентными настройками.

#### Scenario: Изолированная проверка модели
- **WHEN** задана корректная конфигурация gigachat без DATABASE_URL и REDIS_ADDR
- **THEN** eval может проверить модель без инициализации прикладных БД и сессий.
