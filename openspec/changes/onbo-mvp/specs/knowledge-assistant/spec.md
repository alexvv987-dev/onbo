# Spec Delta

## Purpose
Помогать стажёру разбираться в тестовых процессах команды с помощью ответов по разрешённым инструкциям и проверенных серверных инструментов.

## ADDED Requirements

### Requirement: Ответы с разрешёнными источниками
Помощник SHALL получать документы с учётом прав текущего профиля и возвращать доступный источник с подтверждающим фрагментом.
#### Scenario: Найден источник
- **WHEN** стажёр задаёт вопрос по доступной инструкции
- **THEN** ответ содержит название и фрагмент найденного источника.
#### Scenario: Нет основания
- **WHEN** подходящих доступных источников нет
- **THEN** помощник сообщает об отсутствии сведений, не выдумывая регламент.

### Requirement: Проверенные вызовы инструментов
Сервер SHALL разрешать только пять объявленных инструментов, валидировать аргументы и ограничивать цикл пятью итерациями.
#### Scenario: Попытка обойти права
- **WHEN** модель предлагает неизвестную функцию или чужую идентичность
- **THEN** сервер отклоняет вызов и не выполняет запрещённое действие.

### Requirement: Реальная модель и наблюдаемые ошибки
Приложение SHALL поддерживать GigaChat с OAuth и безопасным TLS, показывать ожидание и сообщать о сбое без подмены ответа настоящей модели.
#### Scenario: Модель недоступна
- **WHEN** запрос GigaChat завершился ошибкой или таймаутом
- **THEN** интерфейс остаётся доступным и показывает ошибку с возможностью повтора.
