# Spec Delta

## Purpose
Показывать стажёру персональные шаги адаптации, сохранять выполнение и объяснять следующий доступный шаг без смешения чужих данных.

## ADDED Requirements

### Requirement: Персональный сохраняемый план
Система SHALL показывать четыре шага текущего профиля и сохранять явные отметки ознакомления на сервере.
#### Scenario: Возврат после перезапуска
- **WHEN** стажёр отмечает ознакомление и приложение перезапускается
- **THEN** при повторном входе отметка сохранена только в его плане.

### Requirement: Прогресс зависит от результата сервиса
Система SHALL завершать шаг доступа только по статусу granted; первая задача доступна после выдачи доступа.
#### Scenario: Заявка ожидает
- **WHEN** сервис вернул pending
- **THEN** шаг доступа не завершён и показано ожидание.
#### Scenario: Доступ выдан
- **WHEN** сервис вернул granted
- **THEN** шаг доступа завершён и показан следующий шаг.
