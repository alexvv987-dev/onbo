# Spec Delta

## Purpose
Позволять стажёру безопасно запросить доступ через имитацию корпоративного сервиса и увидеть сохранённый результат выполненного действия.

## ADDED Requirements

### Requirement: Подтверждение неизменяемого черновика
Система SHALL отправлять заявку только после явного подтверждения принадлежащего пользователю неизменяемого черновика.
#### Scenario: Нет подтверждения
- **WHEN** отправка запрошена без подтверждения
- **THEN** сервис не вызывается.
#### Scenario: Чужой черновик
- **WHEN** пользователь подтверждает чужой черновик
- **THEN** операция отклоняется без раскрытия его данных.

### Requirement: Устойчивое выполнение
Система SHALL сохранять операцию до внешнего вызова и использовать устойчивый ключ повтора, возвращая один результат без дублирования.
#### Scenario: Неоднозначный таймаут
- **WHEN** сервис принял заявку, но ответ не дошёл
- **THEN** повтор восстанавливает ту же заявку по ключу.

### Requirement: Сохраняемый жизненный цикл
Система SHALL показывать возвращённый номер и статус pending, granted или rejected; имитация поддерживает воспроизводимые переходы.
#### Scenario: Отказ
- **WHEN** имитация возвращает rejected
- **THEN** результат сохранён и стажёр видит отказ и следующий шаг.
