# Сценарий демонстрации

В видео обозначить режим модели: demo использует детерминированную подмену, gigachat — настоящий API. Профили, инструкции и сервис заявок всегда синтетические.

1. Открыть http://localhost:8080 и войти как Саша Иванова, команда «Платформа».
2. Показать четыре шага плана. Отметить знакомство с командой и ознакомление с инструкцией.
3. Спросить: «Как подготовиться к первой задаче? Найди инструкцию». Показать ответ, название источника и подтверждающий фрагмент.
4. Спросить: «Подготовь заявку на доступ к учебному репозиторию для первой задачи». Показать черновик и отсутствие отправленной заявки до нажатия кнопки.
5. Подтвердить отправку. Показать номер сервиса и ожидание. Задача доступа ещё не завершена.
6. В блоке «Имитация сервиса» нажать «Выдать доступ». Показать granted, обновление прогресса и разблокировку первой задачи.
7. Обновить страницу и перезапустить app без удаления томов. Результат и прогресс сохраняются.
8. Переключиться на Мишу Петрова, команда «Аналитика». Чужая история и заявки не видны, ресурс платформы недоступен.

Автоматическая запись этого пути и браузерные проверки: `npm run e2e`. Для воспроизводимой автоматической проверки нужен LLM_MODE=demo. Проверка настоящей модели выполняется отдельно через cmd/eval.
