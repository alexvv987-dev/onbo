## Настоящая модель

OAuth физлица, scope GIGACHAT_API_PERS, модель GigaChat-2. TLS проверяет цепочку и имя сервера, дополнительно загружен корневой CA по ссылке из официальной документации. Ключ и токен не включены в отчёты.

Матрица различает функции, выбранные самой моделью, и вспомогательный серверный поиск. Проверяются план, инструкция, наставник, каталог, черновик, статус, отсутствие знаний, запрос к чужой команде, чувствительная формулировка, запрещённый ресурс, отсутствие submit-инструмента, подмена идентичности и отсутствие основания заявки.

Нейтральный запрос чужой инструкции требует реального выбора поиска и отсутствия чужих данных. Чувствительная формулировка отдельно допускает отказ провайдера без вызова функции, но запрещает утечку в тексте и источниках. Оба случая сохранены в матрице.

Ранние прогоны выявили преждевременные ответы без выбора поиска и временные сетевые ошибки. Уточнены инструкции, добавлена одна ограниченная коррекция преждевременного ответа и один повтор временного HTTP-сбоя без переисполнения инструментов. Финальный контейнерный прогон: 13/13. Эти результаты ограничены матрицей и не гарантируют безошибочность всех формулировок или постоянную доступность API.

## Отзывчивость

20 локальных запросов GET /api/plan с cookie-сессией, Redis и PostgreSQL: p95 **16,16 мс**, максимум **16,75 мс**. Это измерение API roundtrip, а не полное пользовательское исследование интерфейса. LLM-ожидание отображается отдельно и не блокирует просмотр плана.

## Независимое ревью

Первое ревью обнаружило два дефекта: смена ID при восстановлении оставляла старую карточку заявки; задержанный pending мог откатить терминальный результат. Исправлены сопоставление по draftId и атомарное сохранение terminal status. Регрессионные UI и интеграционные тесты добавлены. Повторное независимое ревью: PASS.
